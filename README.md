Gitora

AI-Powered GitHub Repository Analyzer

Code In. Clarity Out.

Gitora is an AI-powered web application that analyzes GitHub repositories and converts complex codebases into clear, structured explanations.

Features

- 🔍 GitHub repository analysis
- 🤖 AI-powered project understanding
- 📁 File-by-file code analysis
- 🏗️ Architecture explanation
- 🗄️ Database analysis
- 🔐 Authentication analysis
- 🔌 Important API request identification
- 🧩 Dependency analysis
- 💡 Three approaches to rebuild the project
- 💬 Ask questions about the repository
- 📄 Downloadable PDF analysis report
- 💻 Selected source-code display in the report

Technology Stack

- Python
- Flask
- Flask-SQLAlchemy
- OpenAI API
- GitHub API
- ReportLab
- HTML
- CSS
- JavaScript
- SQLite

Setup

Clone the repository and install the required dependencies:

pip install -r requirements.txt

Create a ".env" file and add the required API credentials.

Then start the Flask application.

Security

API keys and environment variables are stored in ".env" and are intentionally excluded from GitHub.

Purpose

Gitora helps developers understand unfamiliar GitHub repositories faster by transforming source code into structured explanations, architecture insights, and actionable documentation.
